# Notes for Claude Code sessions on this repository

- When interacting with Cloudflare, use the cf CLI unless the project has a Wrangler configuration file. (The publisher's domain,
  crowmade.app, and the web pages in `site/` live on Cloudflare; LAUNCH.md says what is set up and what is not.)
- The owner's personal email address must never appear anywhere: not in code, tests, documents, commits, builds, the demo or the
  chat. The only public address is the publisher's support address on crowmade.app. The languages suite guards this.
